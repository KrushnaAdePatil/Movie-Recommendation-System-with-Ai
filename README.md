# Movies World - Premium Movie & Series Suggestion System CinePixel is a modern, responsive web application for movie and TV show lovers to browse, filter, search, and discover media. Implemented strictly in Python (Flask) and HTML5 (CSS3 / JS), it integrates the TMDb API to suggest movies and series from **1991 to the latest releases**, along with detailed runtimes, trailers, and streaming provider information ("Where to Watch"). --- ## 🌟 Key Features - 🔄 **Dual Databases**: Seamlessly toggle between Movies and TV Series (TV Shows). - 📅 **Advanced Year Filtering**: Dynamically filter catalog suggestions and search results from **1991 to the latest year (2026)**. - 🎭 **Genre-Based Suggestions**: Specially mapped tags for **Adventure**, **Horror**, **Thriller**, and **Drama** with instant discover queries. - 📡 **"Where to Watch" (Watch Providers)**: Fetches real-time streaming availability (flatrate providers like Netflix, Apple TV, Amazon Prime, and Disney+) with regional fallback logic. - ⏱️ **Timeline & Details**: Display accurate timeline runtimes (e.g., `2h 15m` for movies and exact seasons/episode counts for shows). - 🎬 **Backdrop Trailers & Recommendations**: Play official YouTube trailers directly in the details modal and explore modern recommendation cards. - 💎 **Premium Glassmorphism UI**: High-end dark theme design using sleek translucent panels, ambient background gradients, responsive layouts, and smooth card scale effects. --- ## 🛠️ Technology Stack - **Backend**: Python 3.x, Flask (for API routing and server runtime), Python-dotenv, Requests (making TMDB queries). - **Frontend**: HTML5, Vanilla CSS3 (Custom property variables, Flex/Grid, Keyframe animations), Vanilla JS (Fetch API, asynchronous controllers). - **External API Service**: TMDb API (Alternative mirror `https://api.tmdb.org` configured for reliable connections). --- ## 🚀 Getting Started ### 1. Prerequisites - Python 3.10+ installed. - TMDb API Key (Already pre-configured in `app.py`). ### 2. Setup & Installation Clone or copy this repository into a folder and navigate to the project directory: ```bash cd MoviesSuggestion ``` Install the required packages using the virtual environment interpreter: ```bash venv\Scripts\pip.exe install -r templates/requirement.txt ``` ### 3. Running the Server Run the Flask application: ```bash venv\Scripts\python.exe app.py ``` ### 4. Viewing the Application Open your web browser and go to: ``` http://127.0.0.1:5000/ ``` --- ## 📂 Project Directory Structure ```text MoviesSuggestion/ │ ├── app.py # Flask application backend (unified TMDb API routes) ├── walkthrough.md # Implementation walkthrough & testing guidelines ├── README.md # GitHub repository overview & usage (this file) │ ├── templates/ │ ├── home.html # Main template containing layout grid, wrappers, and modal │ └── requirement.txt # Python backend dependencies │ └── static/ ├── css/ │ └── style.css # Premium glassmorphic stylesheets & glow aesthetics └── js/ └── script.js # Asynchronous controllers coordinating API events & sliders ``` # Movies-Recommendation-System-With-AI
